# Timer

A lightweight desktop timer and stopwatch built with plain HTML, CSS, and JavaScript.

## Features

- Editable hours, minutes, and seconds
- Quick presets: 1 min, 1:30, 2, 3, 5, 10, 15, and 25 min
- Start, pause, reset, and clear controls
- Quick +/− time adjustments
- Native browser sound when the timer finishes
- Remaining time shown in the browser tab title
- Separate stopwatch mode
- Keyboard shortcuts: `Space` = start/pause, `R` = reset
- Uses an absolute end timestamp, so background-tab throttling does not make the timer drift
- Responsive dark UI

## GitHub Pages

To publish it:

1. Open this repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/(root)**.
5. Save.

GitHub will then show the public Pages URL.
